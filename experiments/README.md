# Experiments

Small, isolated prototypes for **The Consequence Machine** (Creative Web S2).

Use this folder to test ideas before moving working features into the main application.

Potential experiments:
- Pixel-art / low-resolution 3D planet rendering with Three.js and Threlte
- Procedural planet textures and terrain
- Mouse-drag planet rotation and camera travel
- Planetary conditions, habitability and simulation rules
- Timeline, replay and comparison

Keep each experiment in its own subfolder, with a short README explaining what was tested, how to run it and what was learned.
